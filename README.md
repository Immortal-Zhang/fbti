## 运行 / Run

Node.js 24 · Next.js · React · TypeScript

```sh
git clone https://github.com/Immortal-Zhang/which-factory.git
cd which-factory
npm ci
npm run dev -- --port 3127
```

打开 / Open [127.0.0.1:3127](http://127.0.0.1:3127). `npm run check`：lint + types + 480 tests + build.

中文界面；无需账号、数据库或AI API。仅供娱乐，不是心理诊断。<br>
Chinese UI. No account, database or AI API required. For entertainment, not psychological diagnosis.
