# 计分与复现约定 · hum-1

这是娱乐与自我探索的内容分类方法，不是心理诊断，不主张经过科学验证的测量效度。分数只表示本轮回答在原创题库中的相对方向；不代表能力、健康或关系质量。

## 数据契约

规范轴顺序固定为 `energy → expression → navigation → connection`。20 道题按四轴交错出现，每轴 5 题、每题等权。当前 `clear-3` 界面每题提供 3 项，原始 `value` 为 0、2、4；底层仍保留历史五档 0、1、2、3、4，供旧答案恢复和报告编号使用。屏幕位置与计分值解耦，选项 ID 是保存答案的依据。

`scoreAnswers` 要求完整的 20 条 `{ questionId, optionId }`。非数组、缺失、额外、重复题目、未知题目、非法选项和额外答案字段均抛出 `ScoringError`，不能补默认答案或静默丢弃错误。未来进度保存应保存未完成答案，但只在完整校验通过后调用最终评分。

## 正反向与标准化

正向题的有效分为 `value`，反向题为 `4 - value`，只反转一次。每轴有效分总和范围 0～20，标准分为 `总和 × 5`，范围 0～100，新三选答题分数以 10 为步长；含历史答案时仍支持步长 5。不使用随机数、权重猜测、四舍五入或当前时间。

例如某轴五题有效分为 `4、1、3、0、2`，总和为 10，标准分是 50。原始选项值为 4 的反向题对该轴贡献 0。

## 连续倾向与基础型号

| 分数区间        | 显示分带 | 解读                                     |
| --------------- | -------- | ---------------------------------------- |
| 0 ≤ 分数 < 40   | `low`    | 倾向轴的左侧                             |
| 40 ≤ 分数 ≤ 60  | `middle` | 双模式 / 中间倾向，`dominant = balanced` |
| 60 < 分数 ≤ 100 | `high`   | 倾向轴的右侧                             |

`intensity = abs(分数 - 50) × 2`，供未来视觉呈现倾向强度使用，不可称为置信度或准确率。

为了索引 16 个基础设备，每轴 `<50` 记为内部位 0，`≥50` 记为内部位 1，拼接得到 `0000`～`1111`。50 的归属只是确定性的平局规则，不意味着右侧倾向。40～60 的报告必须使用平衡文案；不得仅凭型号名、定位、标签宣称强烈倾向。内部四位键不作为面向用户的人格标签。

连续分数、分带和题目级指纹共同参与后续内容选择，因此相同型号不必得到相同说明书。分数跨过 50 可能更换基础型号，而 40～60 仍应呈现中间倾向。这个边界属于娱乐分类设计，不是测量结论。

## 可复现规则

回答先按题库固定顺序规范化，再将内容版本 `hum-1` 与题目/选项 ID 序列作 JSON 编码，使用 FNV-1a 生成十六进制指纹。重排输入、重复调用、刷新页面或跨设备执行不会改变相同答案的分数、型号与指纹。

指纹只是稳定的文案选择种子，不是密码、安全签名或唯一身份，不能防篡改；未来 URL 仍须独立做版本检查、字段白名单与数据校验。固定题库顺序和选项 ID 属于版本契约，改题、改映射、改评分或改文案规则都必须考虑内容版本更新。

## 本阶段验证与边界

自动化测试覆盖极值、每轴全部 21 个可达标准分、正反向计分、中间带两端及 50 平局、所有 16 型可达、输入顺序不变、输入不被修改、同分不同答案保留不同指纹及非法输入拒绝。内容契约另检验 20 题、100 个历史选项记录（当前界面仅展示其中 60 项）、每轴 5 题、双向题分布和 16 份完整型号档案。

语义质量仍需人工审阅：测试能检验内容结构，不能证明所有文案绝无语义矛盾，更不能证明娱乐题库具有科学测量效度。第二阶段已接通版本化进度与正式答题流程，对改答、刷新、重测进行了实际浏览器验收。好友8题与公开分享已由独立契约实现，不改动本页的hum-1自测评分规则。
